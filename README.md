# Drifter Crisis

Extracted files related to the **F星域 / 流浪者 (Drifter / Wanderer / Contractor)** events from the [KuatAncientEmpire](https://github.com/VermilionLP/KuatAncientEmpire) Stellaris mod.

## Included

- Solar system initializers for the white-hole / F-system crisis
- Related event chains (`kuat_legacy_events`, `kuat_post_shadow_legacy_events`, `kuat_situation_events`, `kuat_eternal_invasion_events`)
- Country types (`kuat_contractor`, `Kuat_F_Area_Guardian`, etc.)
- Drift warship sections, components, megastructures (Vela's Anchor)
- Localisation (Chinese & English) for Wanderer / F system names
- Ship sizes and other supporting scripts
- Graphics (Drft fleet warship models, flags)

## Note

This is a subset extracted for convenience focusing on the Drifter / F-system / Wanderer content.

Original mod: https://github.com/VermilionLP/KuatAncientEmpire
